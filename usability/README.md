# Тест кабинета тестировщиками

Анкета для людей, которые проходят кабинет «Слеза Белый Сайт». Ответы уходят в Google Таблицу через Google Apps Script. Ни бэкенд, ни база не нужны.

| Файл | Что это |
|---|---|
| `index.html` | Анкета для тестировщика: 14 заданий по пути в кабинете, ошибки, итог, кнопка «Сохранить» |
| `answers.html` | Страница для команды: ответы и порядок исправлений, вход по паролю |
| `tasks.js` | Общее: адрес таблицы (`ENDPOINT`), задания, сборка строки таблицы |
| `apps-script.gs` | Код приёмника, вставляется в Google Таблицу |
| `style.css` | Стили обеих страниц |

## Подключить таблицу (один раз, 5 минут)

1. Создайте пустую Google Таблицу.
2. «Расширения» → «Apps Script». Удалите всё в редакторе и вставьте `apps-script.gs`.
3. В строке `const ADMIN_KEY = '…'` впишите свой пароль. По нему открывается страница ответов.
4. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение».
   - «Запуск от имени»: **я**.
   - «У кого есть доступ»: **все**.
5. Нажмите «Начать развёртывание» и разрешите доступ к таблице. Google предупредит, что приложение не проверено: «Дополнительно» → «Перейти к проекту».
6. Скопируйте адрес веб-приложения (`https://script.google.com/macros/s/…/exec`) и впишите его в `ENDPOINT` в `tasks.js`.

Если потом поменяете код скрипта: «Управление развёртываниями» → карандаш → версия «Новая». Адрес останется прежним.

## Как это работает

- Одна строка таблицы — один тестировщик. Повторное «Сохранить» обновляет его строку, а не добавляет новую.
- В таблице читаемые колонки по каждому заданию. В последней колонке, «Данные (JSON)», лежат полные ответы для `answers.html`.
- Черновик хранится в браузере тестировщика: закрыл вкладку — ответы на месте.
- «Начать заново» заводит нового тестировщика на том же устройстве. Уже сохранённые ответы остаются в таблице.
