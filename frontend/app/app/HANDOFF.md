# Кабинет «Слеза Белый Сайт» в React — передача в новую сессию

Состояние на 22.09.2026 (вечер: собраны вход, настройки, меню аккаунта, окна). Прототип без бэкенда: вся логика в браузере, состояние —
анкета в `sessionStorage` (`start/_shared/anketaState.js`).

Живая ссылка: https://xpommo.github.io/sleza-web/anketa/app/register/
На каждом экране — панель **«Макет»** (правый нижний угол): 13 готовых состояний
и переходы на все экраны. Проверять руками — через неё.

## Главное правило

Пользователь: «берём только дизайн, логика остаётся». Логику, тексты и решения не
придумываем — переносим из утверждённого и сверяем. Много времени ушло на правки,
которые легко потерять.

   решений и открытые вопросы владельца.

Решения, которые легко сломать:
- **Счёт общий на аккаунт** (владелец, 18.09): «Подписка» — в меню аккаунта
  (`/app/billing`), не сайта. У сайта — состояние и «Отключить этот сайт» на «Обзоре».
- После отключения/неоплаты уже опубликованные страницы документов **остаются доступны

- Шаг «Данные клиентов» **никогда не пропускается** (9.09).

  третьим лицам».
- Баннер cookie — без кнопки «Отклонить». Тема виджета одна на шаг 5 и «Виджет».

## Чего нет

Сделано 22.09: вход, вход по почте (на месте, см. выше), настройки, меню аккаунта,
`modal-no-script`, `modal-req-invoice` (9 полей, «Как в анкете / Другие реквизиты» →

Сквозной проход 22.09 (вечер) — сверка с живым макетом, пункты Ивана, целостность:
- **Один каркас на анкету и кабинет**: `SidebarShell` (капля вместо фонарика, та же
  ширина, «Поддержка» и аккаунт внизу), общая шапка шага `AnketaFrame` (заголовки
  28/36 как в кабинете, плашки «Защищённая форма / Почти готово» убраны).
- **Мобильный как в макете**: кабинет — таббар `SiteTabbar` (Обзор/Документы/Виджет/
  Ещё), анкета — панель `FunnelBar` (Назад · шаги · Далее), кнопки нажимают настоящие
  `[data-funnel-back]`/`[data-funnel-next]`. Отступ — `body.has-bottombar`.
- **Петля «ответ → документ»** (очередь 3 макета): `docOrigin()` в `lib/docPackage.js`,
  варианты ответов — `lib/anketaOptions.js`. На шаге 5 в раскрытом документе «Собрано
  по ответу … · Изменить ответ →». Проверять сменой ответа, не осмотром.
- Иван п.9: «Платформа» — радио (`Tile radio`). «Зачем это нужно» — один вид, у блоков
  в шапке справа (шаги 1, 4 сведены к 2–3). Шаг 1: «Ваша роль в компании», «Куда вам
  писать». Шаг 4: до выбора формы владения — нейтральные подписи.
- Одно состояние — одно имя: «Счёт выставлен», «Документы собраны · скрипт не
  установлен», «Оплачено, ждём код на сайте» — одинаково в «Моих сайтах» и «Обзоре».
- Cookie-баннер сканера на `/app/*` не показывается.

Осталось:
1. «Поддержка» без «← Назад» (в макете есть `support-back`, как у Настроек).
2. После регистрации до шага «Ваш профиль» в углу стоит имя из мока («Кирилл») рядом с
   почтой, которую человек ввёл, — имени мы ещё не знаем. Решить, что показывать.
3. Петля «ответ → результат» на «Виджете» (какие плашки в подвале и почему) — в макете
   тоже не сделана.

## Как проверять и публиковать

```bash
cd frontend && export NVM_DIR="$HOME/.nvm" && source "$NVM_DIR/nvm.sh"
node scripts/build-ghpages.mjs                      # статическая сборка в frontend/out
cp -R out /tmp/srv/sleza-web/anketa                 # локально: python3 -m http.server 8899 в /tmp/srv
# публикация: worktree ветки gh-pages в /tmp/ghp → rm -rf anketa && cp -R ../frontend/out anketa → commit → push
```
Playwright — `backend/node_modules/playwright/index.mjs`. Проверять сценарием, а не
глазами: переходы, состояния, F5/«Назад», ширины 390/1024/1440, ошибки консоли.
`master` не пушить без просьбы (Vercel деплоит с него). `gh-pages` — пушим.

Выгрузка экрана макета (`/tmp/scr.sh`):
```bash
F=/tmp/mvp2.html; git show anketa-hierarchy:cabinet-mvp.html > $F
s=$(grep -n "id=\"$1\"" "$F" | head -1 | cut -d: -f1)
e=$(awk -v s=$s 'NR>s && /id="s-[a-z0-9-]+"/ && /<(section|div|main)/{print NR; exit}' "$F")
awk -v a=$s -v b=${e:-$((s+600))} 'NR>=a && NR<b' "$F" | sed -E 's/<!--/\x01/g; s/-->/\x02/g' | tr '\n' ' ' \
 | sed -E 's/\x01([^\x02]*)\x02/\n    ⟦\1⟧\n/g; s/<[^>]*>/\n/g; s/[ \t]+/ /g' | grep -v '^\s*$'
```
